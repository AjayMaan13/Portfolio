About Me

I build software, and I make a point of proving it works.

I'm a Computer Programming & Analysis student at Seneca Polytechnic (graduating December 2026) with a 4.0 GPA and three President's Honour List recognitions. I've been coding since I was 12.

I just finished an 8-month co-op with the Government of Ontario, working on SAMS, the case-management platform behind ODSP and OCSD benefits. There I automated regression testing (cutting test cycles from 8 hours to 28 minutes), built a MERN test-scenario platform for 100+ engineers, and built AI agents for log triage and document search.

On my own time I build things that can be tested, measured and explained: an order API checked with 3,000 parallel orders, a cloud data pipeline, a debugger for failing AI agents. I also mentor: 20+ open-source contributors, hackathon teams and first-year students. When I'm away from the keyboard I'm reading classic novels and AI books, or playing volleyball and cricket.
